# 접근 / 멀어짐 판단 설계

> 목표: 사이렌의 시간 흐름에서 접근/멀어짐/유지를 판단한다.
> 구현: [`approach/detector.py`](../../approach/detector.py),
> [`pipeline/motion_fusion.py`](../../pipeline/motion_fusion.py)

## 현재 구조

```text
사이렌 확정
   ├─ speed_neural_dir.onnx (실제 5초 창)
   │    └─ 정지/접근/멀어짐 확률 + 원시 이동점수
   └─ 최근 3초 신호
        ├─ log 대역에너지 기울기
        └─ 대표주파수 기울기·R²·톤 지속률 (직접 도플러)
                         ↓
                 조건부 C 융합
                         ↓
               접근 / 멀어짐 / 유지 / 미상
```

세 값을 고정 가중 평균하지 않는다. 모델, 에너지 기울기, 주파수 기울기는 단위와 오차 원인이
서로 다르다. 각 증거를 독립 계산하고 일치·충돌 조건에 따라 하나를 선택한다.

## 신호별 역할

### 음량 추세

300~2500 Hz 대역의 log-power 기울기를 계산한다.

- 양수: 소리가 커짐 → 접근의 주 증거
- 음수: 소리가 작아짐 → 멀어짐의 주 증거
- deadband 안: 유지

절대 음압이 아니라 한 이벤트 안에서의 변화량을 사용한다. 다만 사이렌 원본 자체의 음량
변조, 자동 이득 조절, 차폐와 반사에도 영향을 받으므로 단독 판정은 정적 오경보가 많았다.

### 직접 도플러

0.5초 프레임에서 대표 주파수를 추적하고 최근 3초의 Hz/s 기울기를 계산한다. 큰 변화량만으로
믿지 않고 다음 값을 곱해 유효도를 만든다.

- 주파수 변화량
- 톤이 검출된 프레임 비율
- 선형 추세 설명력 R²

실제 통과에서는 관측 주파수가 높은 쪽에서 낮은 쪽으로 연속 이동할 수 있고, 사이렌 자체도
주기적으로 주파수를 바꾼다. 원래 발진 주파수를 모르는 단일 피크 기울기는 접근/멀어짐을
안정적으로 단독 판정할 수 없다. 따라서 C에서는 충돌을 푸는 보조 증거로만 쓴다.

### `speed_neural_dir.onnx`

64×216 log-mel 5초 창에서 원시 speed head와 정지/접근/멀어짐 dir head를 낸다. 무음으로
채운 짧은 창은 크게 오판하므로 실제 신호 5초가 쌓인 뒤에만 실행한다.

모델은 순수 도플러 계산기가 아니다. 주파수 패턴뿐 아니라 음량 변화에도 반응하는 학습 기반
판정기다. 공개 데이터 검증에서 speed head의 km/h와 3단계 속도는 신뢰도가 부족했으므로
화면에 표시하지 않고 진단값으로만 보존한다. 융합에는 dir head 확률만 사용한다.

## 조건부 C 규칙

- 음량은 deadband 0.20으로 접근/멀어짐/유지를 정하고 주 판단으로 둔다.
- 모델과 음량이 일치: 같은 방향 채택
- 충돌: 모델 신뢰도 0.55 이상이고 직접 도플러 유효도 0.20 이상이며 둘이 같은 방향일 때만
  모델 쪽으로 변경
- 그 외 충돌: 음량 판단 유지
- 음량 판단 불가: 신뢰도 높은 모델로 임시 폴백, 둘 다 불충분하면 `UNKNOWN`
- 마지막에 약 1.5초 다수결

선택 문턱과 비교 결과는 [검증 문서](validation.md)에 기록한다.

## 출력 해석

- `motion`: 최종 C 융합 결과
- `gauge`, `proximity`, `rel_distance`: 이벤트 내 음량 최고점에 대한 상대 근접 정보
- `energy_slope`, `frequency_slope`, `doppler_confidence`: 융합 진단값
- `speed_level`: 과거 호환용 음량 변화 강도. 검증된 차량 속도가 아니며 UI에 표시하지 않음
