# 전처리 (Preprocessing) 단계별 설명

> 코드: [`classifier/preprocessing.py`](../../classifier/preprocessing.py)
> 한 줄 요약: **제각각인 오디오 파일 → 똑같은 크기의 작은 "이미지" `(1, 64, 32)` 로 통일**

---

## 왜 전처리가 필요한가

UrbanSound8K 파일은 **채널·샘플레이트·길이가 제각각**이다.

| 파일 | 샘플레이트 | 채널 | 길이 |
|------|:---:|:---:|:---:|
| 예시 A | 44100 | 2(스테레오) | 4초 |
| 예시 B | 48000 | 1(모노) | 2.5초 |

신경망 모델은 **입력 크기가 항상 같아야** 하므로, 전처리가 전부 **1채널·16kHz·1초·(1,64,32)** 로 통일한다.
> 참고: 채널·샘플레이트는 CSV가 아니라 **wav 파일 안(헤더)** 에 있다. `soundfile.info(path)` 또는 "파일 우클릭 → 속성 → 자세히"로 확인.

---

## 단계별 (예시: 스테레오·44100Hz·4초 사이렌)

```
(176400, 2)  →①모노→ (176400,) →②리샘플→ (64000,) →③1초→ (16000,)
   →④Mel→ (64,32) →⑤dB→ (64,32) →⑥정규화→ (64,32) →⑦채널→ (1,64,32)
```

### ① 모노 변환  `_as_mono_tensor`
- `(176400, 2) → (176400,)` : 좌/우 2채널을 평균내 1채널로.
- 왜: 분류엔 좌우 구분 불필요.

### ② 리샘플  `_resample`
- `44100Hz → 16000Hz` : 1초당 측정 횟수를 줄임 (점→곡선 복원→새 간격으로 다시 찍기).
- 왜: ① 파일마다 다른 샘플레이트 **통일** ② 사이렌/경적은 16kHz로 충분 ③ 가볍고 빠름 ④ YAMNet이 16kHz 요구.
- 주의: 줄이기는 높은음 일부 손실(되돌릴 수 없음)하지만 사이렌/경적엔 영향 없음.

### ③ 길이 고정  `_fix_length`
- `→ (16000,)` : 1초(16000샘플)로. 길면 자르고(현재 앞 1초), 짧으면 0으로 패딩.
- 왜: 모델 입력 길이는 항상 같아야 함.
- 개선 여지: 학습 때 랜덤 1초 구간(증강 효과).

### ④ Mel-spectrogram  `_MEL`  ← 핵심
- `(16000,) 파형 → (64, 32) 격자` : 소리를 **시간×주파수 "이미지"** 로.
  - 세로 64 = 주파수 대역 64개 (`N_MELS=64`)
  - 가로 32 = 시간 조각 32개 (`hop_length=512` → 16000/512 ≈ 32)
  - 각 칸 = 그 (주파수, 시간)에서 소리 세기
- 왜: 파형은 모델이 보기 어렵다. 그림으로 바꾸면 CNN이 패턴 인식 가능.

### ⑤ dB 변환  `_TO_DB`
- `(64,32) 값 0~265 → (64,32) 값 -25~24` : 격자 크기는 그대로, **칸 안 숫자만** 로그(dB)로 압축.
- 왜: ① 소리 세기 범위가 너무 넓어 작은 소리가 묻힘 → 로그로 압축해 작은 소리도 보존 ② 사람 청각이 로그적 ③ 학습 안정.
- ⚠️ `(64,32)`는 격자 크기(불변), `값 0~265`는 칸 안 숫자들의 최소~최대(가변). 둘은 다른 것.

### ⑥ 정규화  `_normalize`
- `값 -25~24 → 평균 0 / 표준편차 1` : 전체를 표준화.
- 왜: 녹음마다 음량 달라도 일관된 범위 → 학습 안정·빠름.

### ⑦ 채널 추가  `unsqueeze(0)`
- `(64,32) → (1, 64, 32)` : 맨 앞 채널 차원 추가.
- 왜: CNN은 (채널, 높이, 너비) 형태 입력. Mel은 흑백 이미지라 채널 1.
- 예외: **MobileNet은 3채널 필요(RGB 사전학습)** → 1채널을 3번 복사(모델 단계에서). YAMNet은 스펙트로그램 대신 파형 입력.

## 출력 두 종류
| 함수 | 출력 | 쓰는 모델 |
|------|------|----------|
| `waveform_to_logmel` | `(1, 64, 32)` log-mel | scratch CNN / MobileNet |
| `prepare_waveform` | `(16000,)` 파형 | YAMNet |

> 학습(dataset)·추론(infer)이 **같은 함수**를 써서 전처리 불일치 버그를 방지.
