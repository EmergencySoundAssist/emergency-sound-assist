# 사이렌 차종 분류

사이렌이 확정된 동안 `subtype_cnn_attn_yt_s42.onnx`로 구급차·경찰차·소방차를 분류한다.
경적과 일반 소음에는 차종 모델을 실행하지 않는다.

## 입력과 출력

| 항목 | 값 |
|---|---|
| 입력 | 검출과 같은 정규화 log-mel `(1, 1, 64, 216)` |
| 출력 순서 | 구급차, 경찰차, 소방차 |
| 단일 tick 최소 확률 | 0.6 |
| 시간 안정화 | 경보 중 약 6초 다수결 |

검출에서 이미 계산한 5초 멜을 그대로 사용한다. 유효 확률이 0.6 미만인 tick은 투표에서
기권하며, 유효 표가 없으면 특정 차종 대신 `긴급차량`으로 표시한다.

```text
5초 사이렌 확정
   ↓
차종 softmax
   ├─ 최대 확률 ≥ 0.6 → 해당 차종에 1표
   └─ 최대 확률 < 0.6 → 기권
   ↓
최근 투표 다수결 → 구급차 / 경찰차 / 소방차 / 긴급차량
```

## 안전 처리

- 모델 파일이 없으면 차종만 생략하고 사이렌 검출은 계속한다.
- 단일 tick 결과를 바로 표시하지 않아 경찰차↔구급차 라벨 깜빡임을 줄인다.
- 차종은 보조 정보다. 사이렌 경보 자체를 켜고 끄는 판단에는 사용하지 않는다.

## 모델 파일

현재 활성 파일은 다음이다.

```text
classifier/models/subtype_cnn_attn_yt_s42.onnx
```

ONNX 변환은 별도 학습 저장소에서 수행한다. 배포물을 교체할 때는 입력 shape, 출력 클래스
순서, 전처리 정규화가 현재 코드와 같은지 반드시 확인한다.

## 남은 검증

현재 문서에는 검증되지 않은 합성 정확도 수치를 제품 정확도로 적지 않는다. 경찰차·구급차·
소방차의 실제 도로 녹음을 source-disjoint로 나눠 클래스별 재현율과 혼동행렬을 측정해야 한다.
