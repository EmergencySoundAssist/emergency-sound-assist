# 용어집

프로젝트에서 자주 쓰는 용어 정리 (팀원 온보딩용).

---

## 오디오 / 신호처리
- **채널(Channel)**: 소리 트랙 개수. 모노=1개, 스테레오=2개(좌/우). 파일마다 다를 수 있음. (형식 정보는 CSV가 아니라 wav 파일 헤더에 있음)
- **샘플레이트(Sample Rate)**: 1초에 소리를 몇 번 "찰칵" 측정하는지(Hz). 우리는 16kHz(초당 16,000번). 높을수록 고음질·데이터 많음.
- **리샘플(Resampling)**: 이미 녹음된 소리의 샘플레이트를 바꾸는 것(예: 44100→16000). 점→곡선 복원→새 간격으로 다시 찍기. 줄이면 높은음 일부 손실(되돌릴 수 없음). 사진 크기 조절과 비슷.
- **청크(Chunk)**: 한 번에 분석하는 오디오 조각. 우리는 1초.
- **Mel-spectrogram**: 소리를 "이미지"처럼 시간(가로)×주파수(세로) 격자로 변환한 것. 각 칸=세기. 우리는 `(64, 32)` = 주파수 64칸 × 시간 32칸. CNN 입력으로 사용.
- **dB 변환(데시벨/로그 스케일)**: 소리 세기를 로그로 압축. 세기 범위가 너무 넓어 작은 소리가 묻히는 걸 막고, 사람 청각(로그)과 맞춤. (격자 크기는 그대로, 칸 안 숫자만 바뀜)
- **정규화(Normalize)**: 값을 평균0/표준편차1로 맞춤. 녹음마다 음량 달라도 일관되게 → 학습 안정.
- **다운믹스(Downmix)**: 여러 채널을 평균내 1채널(모노)로 합치기.
- **MFCC**: Mel-spectrogram을 더 압축한 고전적 음향 특징.
- **shape (형태)**: 데이터의 차원 크기. 예 `(1, 64, 32)` = 채널1 × 높이64 × 너비32. CNN 입력은 (채널,높이,너비) 형태. (배치로 묶이면 맨 앞에 배치 차원이 더 붙음)

## 머신러닝 - 구조
- **백본(Backbone)**: 입력에서 핵심 특징을 뽑는 신경망 몸통. 사전학습된 부분.
- **헤드(Head)**: 백본의 특징을 받아 최종 분류하는 작은 부분. Linear(1층) 또는 MLP(은닉층 포함).
- **임베딩(Embedding)**: 백본이 뽑아낸 특징 벡터 (예: YAMNet은 1024차원).
- **CNN**: 합성곱 신경망. 이미지/스펙트로그램 패턴 인식에 강함.

## 머신러닝 - 학습 방식
- **사전학습(Pretrained)**: 거대 데이터로 미리 학습된 모델. (YAMNet=오디오, MobileNet=이미지)
- **scratch(밑바닥 학습)**: 사전학습 없이 랜덤 초기화에서 우리 데이터로만 학습.
- **전이학습(Transfer Learning)**: 사전학습 모델을 가져와 우리 문제에 맞춤.
- **동결(Frozen)**: 백본 가중치를 고정하고 head만 학습.
- **파인튜닝(Fine-tuning)**: 백본 가중치까지 함께 학습(전체 학습).
- **zero-shot**: 학습 없이 사전학습 모델 출력을 그대로 매핑해 사용.
- **과적합(Overfitting)**: 학습 데이터를 외워버려 실제 성능이 떨어지는 현상.
- **class weight**: 클래스 불균형 보정을 위해 적은 클래스에 가중치를 더 주는 것.

## 평가
- **fold / 교차검증**: 데이터를 여러 묶음으로 나눠 학습/평가. UrbanSound8K는 10-fold 제공.
- **macro-F1**: 클래스별 F1의 평균. 불균형 데이터에서 정확도보다 공정한 지표.
- **혼동행렬(Confusion Matrix)**: 어떤 클래스를 어떤 클래스로 헷갈렸는지 표.

## 방향 추정 (DoA)
- **DoA**: Direction of Arrival. 소리가 오는 방향.
- **TDOA**: 마이크 간 소리 도착 시간 차이 → 방향 계산.
- **GCC-PHAT**: 노이즈/잔향에 강하게 시간 차이를 재는 표준 방법.
- **빔포밍(Beamforming)**: 특정 방향 소리를 강조/제거하는 기술.

## 접근 판단
- **도플러 효과(Doppler)**: 음원이 다가오면 주파수↑, 멀어지면 주파수↓.

## 개발 환경
- **의존성(Dependency)**: 우리 코드가 동작하려면 필요한 외부 라이브러리(torch 등). `pip install`로 설치. 목록은 `requirements.txt`.
- **가상환경(venv)**: 프로젝트마다 독립된 파이썬 환경. 패키지를 전역에 안 깔고 프로젝트 안에만 설치해 다른 프로젝트와 안 섞이게 함. 활성화 시 `(.venv)` 표시. 전역 패키지와 별개로 동작.
- **config.py**: 프로젝트 설정값(경로·라벨매핑·하이퍼파라미터·실험목록)을 한곳에 모은 파일. 값 바꿀 땐 이 파일만 수정. (리모컨 같은 역할)
- **EXPERIMENTS**: config.py의 실험 목록. `{backbone, head, freeze_mode}` 한 줄로 실험 하나 정의 → 추가/제거 쉬움.
