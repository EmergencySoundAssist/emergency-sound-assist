# 용어집

프로젝트에서 자주 쓰는 용어 정리 (팀원 온보딩용).

---

## 오디오 / 신호처리
- **샘플레이트(Sample Rate)**: 1초에 소리를 몇 번 측정하는지. 우리는 16kHz(초당 16,000번).
- **청크(Chunk)**: 한 번에 분석하는 오디오 조각. 우리는 1초.
- **Mel-spectrogram**: 소리를 "이미지"처럼 시간×주파수 그림으로 변환한 것. CNN 입력으로 사용.
- **MFCC**: Mel-spectrogram을 더 압축한 고전적 음향 특징.
- **다운믹스(Downmix)**: 여러 채널을 평균내 1채널(모노)로 합치기.

## 머신러닝 - 구조
- **백본(Backbone)**: 입력에서 핵심 특징을 뽑는 신경망 몸통. 사전학습된 부분.
- **헤드(Head)**: 백본의 특징을 받아 최종 분류하는 작은 부분. Linear(1층) 또는 MLP(은닉층 포함).
- **임베딩(Embedding)**: 백본이 뽑아낸 특징 벡터 (예: YAMNet은 1024차원).
- **CNN**: 합성곱 신경망. 이미지/스펙트로그램 패턴 인식에 강함.

## 머신러닝 - 학습 방식
- **사전학습(Pretrained)**: 거대 데이터로 미리 학습된 모델. (YAMNet=오디오, MobileNet=이미지)
- **scratch(밑바닥 학습)**: 사전학습 없이 랜덤 초기화에서 우리 데이터로만 학습.
- **전이학습(Transfer Learning)**: 사전학습 모델을 가져와 우리 문제에 맞춤.
- **동결(Frozen)**: 백본 가중치를 고정하고 head만 학습.
- **파인튜닝(Fine-tuning)**: 백본 가중치까지 함께 학습(전체 학습).
- **zero-shot**: 학습 없이 사전학습 모델 출력을 그대로 매핑해 사용.
- **과적합(Overfitting)**: 학습 데이터를 외워버려 실제 성능이 떨어지는 현상.
- **class weight**: 클래스 불균형 보정을 위해 적은 클래스에 가중치를 더 주는 것.

## 평가
- **fold / 교차검증**: 데이터를 여러 묶음으로 나눠 학습/평가. UrbanSound8K는 10-fold 제공.
- **macro-F1**: 클래스별 F1의 평균. 불균형 데이터에서 정확도보다 공정한 지표.
- **혼동행렬(Confusion Matrix)**: 어떤 클래스를 어떤 클래스로 헷갈렸는지 표.

## 방향 추정 (DoA)
- **DoA**: Direction of Arrival. 소리가 오는 방향.
- **TDOA**: 마이크 간 소리 도착 시간 차이 → 방향 계산.
- **GCC-PHAT**: 노이즈/잔향에 강하게 시간 차이를 재는 표준 방법.
- **빔포밍(Beamforming)**: 특정 방향 소리를 강조/제거하는 기술.

## 접근 판단
- **도플러 효과(Doppler)**: 음원이 다가오면 주파수↑, 멀어지면 주파수↓.
