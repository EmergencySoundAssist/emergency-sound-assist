# 용어집

현재 코드와 문서에서 사용하는 용어를 기능별로 정리한다.

## 오디오·신호 처리

- **샘플레이트(sample rate)**: 1초 동안 소리를 측정하는 횟수. 기본 입력은 16 kHz다.
- **틱(tick)**: 통합 파이프라인이 한 번 처리하는 오디오 조각. 기본값은 0.15초다.
- **발화(utterance)**: STT가 한 문장처럼 묶어 인식하는 연속 음성 구간. 여러 입력 틱으로 구성된다.
- **Log-Mel spectrogram**: 시간에 따른 주파수 에너지를 Mel 축과 로그 크기로 표현한 모델 입력 특징.
- **RMS**: 신호의 평균적인 크기. 음량 변화와 energy VAD 계산에 사용한다.
- **SNR**: 신호와 잡음의 비율. 값이 낮을수록 잡음이 강하다.
- **다운믹스(downmix)**: 여러 오디오 채널을 모노 한 채널로 합치는 것.

## 모델·실행 엔진

- **ONNX**: 학습 프레임워크와 실행 환경 사이에서 모델을 옮기기 위한 포맷. 검출·차종·접근 모델에 사용한다.
- **ONNX Runtime**: ONNX 모델을 실행하는 런타임.
- **Execution Provider(EP)**: ONNX Runtime이 실제 연산을 맡기는 백엔드. 이 프로젝트는 Jetson에서 TensorRT, CUDA, CPU 순으로 사용을 시도한다.
- **TensorRT**: NVIDIA GPU에서 ONNX 계열 모델 추론을 최적화하는 엔진. GPU와 별도 하드웨어가 아니다.
- **CUDA**: NVIDIA GPU 연산 플랫폼. ONNX Runtime CUDA EP와 STT용 CTranslate2가 이를 이용할 수 있다.
- **CTranslate2**: faster-whisper가 Whisper를 실행할 때 쓰는 추론 엔진. Jetson에서는 CUDA 빌드가 필요하다.
- **logit**: softmax를 적용하기 전 모델의 원시 출력 점수.
- **confidence**: 모델 출력이나 신호 품질을 0~1 범위로 정리한 신뢰도.
- **margin**: 가장 높은 클래스 점수와 두 번째 점수의 차이. 클수록 분류가 명확하다.

## 경보·분류

- **검출(detection)**: 입력을 사이렌·경적·일반 소리로 구분하는 1차 판단.
- **PRE 예비경보**: 2초 모델에서 긴급음 가능성을 먼저 알리는 상태.
- **확정 경보**: 5초 모델과 상태기계 조건을 통과한 사이렌 또는 경적 경보.
- **차종(subtype)**: 확정된 사이렌을 구급차·경찰차·소방차로 세분화한 결과.
- **상태기계(state machine)**: 순간 예측 하나가 아니라 최근 예측의 연속성과 시간을 이용해 PRE·확정·해제를 결정하는 로직.
- **히스테리시스(hysteresis)**: 경보를 켜는 조건과 끄는 조건을 다르게 해 경계에서 상태가 흔들리지 않게 하는 방식.
- **hangover**: 신호가 잠깐 약해져도 일정 시간 결과를 유지하는 구간.

## 방향 추정(DoA)

- **DoA(Direction of Arrival)**: 소리가 들어오는 방향.
- **TDOA**: 같은 소리가 각 마이크에 도착한 시간 차이.
- **GCC-PHAT**: 위상 정보를 강조해 두 채널 사이의 시간 차이를 추정하는 방법.
- **SRP-PHAT**: 여러 마이크의 PHAT 응답을 후보 방향별로 합쳐 공간 스펙트럼을 만드는 방법. 통합 방향 추정의 기본 알고리즘이다.
- **MUSIC**: 신호·잡음 부분공간을 분리해 음원 방향을 찾는 알고리즘.
- **공간 스펙트럼**: 후보 각도별 음원 가능성 분포. 봉우리(peak)가 추정 방향이 된다.
- **트래킹(tracking)**: 시간상 가까운 방향 결과를 같은 음원으로 연결하고 순간적인 튐을 줄이는 처리.

## 접근·멀어짐

- **도플러 효과(Doppler effect)**: 음원과 관찰자의 상대 운동으로 관측 주파수가 변하는 현상.
- **직접 도플러 특징**: 최근 신호의 스펙트럼 변화를 코드로 계산해 주파수 상승·하강 증거를 만드는 값.
- **음량 기울기**: 최근 구간에서 로그 음량이 증가하거나 감소하는 정도. 접근·멀어짐의 주된 보조 증거다.
- **조건부 융합**: 모델·음량·직접 도플러 값을 단순 평균하지 않고, 각 신뢰 조건에 따라 사용할 근거를 선택하는 방식.
- **원시 speed head**: `speed_neural_dir.onnx`의 숫자 출력. 차량 km/h로 검증되지 않아 현재는 진단용으로만 보존한다.

## STT

- **STT(Speech-To-Text)**: 음성을 텍스트로 변환하는 기능. faster-whisper를 사용한다.
- **VAD(Voice Activity Detection)**: 입력에 말소리가 있는지 판별하는 처리. Silero를 우선 사용하고 WebRTC, energy 방식으로 폴백한다.
- **Silero VAD**: 신경망 기반 음성 구간 검출기. 현재 기본 VAD다.
- **generation**: 경보로 STT를 중단한 뒤 이전 작업 결과가 늦게 화면에 나타나지 않도록 작업 세대를 구분하는 번호.
- **CER(Character Error Rate)**: 정답과 인식 문장의 문자 편집 거리를 정답 문자 수로 나눈 한국어 STT 오류율. 낮을수록 좋다.

## 평가

- **재현율(recall)**: 실제 해당 클래스 중 올바르게 찾아낸 비율.
- **균형 정확도(balanced accuracy)**: 클래스별 재현율의 평균. 클래스 개수가 불균형할 때 유용하다.
- **source-disjoint 평가**: 같은 원본 녹음에서 파생된 샘플이 학습·튜닝과 평가 양쪽에 섞이지 않게 나누는 방식.
- **교차검증(cross-validation)**: 데이터를 여러 묶음으로 나누고 평가 묶음을 바꾸어가며 반복 검증하는 방법.
