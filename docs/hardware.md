| 장비 | 역할 |
|------|------|
| **NVIDIA Jetson Orin Nano Super Dev Kit** | 메인 연산 (분류 모델·방향·접근 알고리즘 실행) |

## ReSpeaker XVF-3000 채널 구성 (중요)

물리 마이크는 **4개**지만, USB로는 **6채널**이 나온다.

| 채널 | 내용 | 용도 |
|:----:|------|------|
| 0 | 처리된 오디오 (빔포밍/AEC) | **분류·차종·접근·STT** |
| 1 | 마이크1 원본(raw) | 방향 |
| 2 | 마이크2 원본 | 방향 |
| 3 | 마이크3 원본 | 방향 |
| 4 | 마이크4 원본 | 방향 |
| 5 | 재생(playback) 참조 | 보통 미사용 |

- **기본 펌웨어가 6채널 제공** → 별도 플래시 불필요.
- 파이썬에서 `sounddevice`로 채널 6개로 열어 슬라이스:
  ```python
  data, _ = stream.read(n)   # (n, 6)
  processed = data[:, 0]     # 분류·차종·접근·STT
  raw4 = data[:, 1:5]        # 방향
  ```

### 자체 DoA 읽기 (별개 경로)
- 방향 값은 **오디오 스트림이 아니라 USB 제어 채널**로 읽음 (`pyusb` + `doa/respeaker_tuning.py`).
- `Tuning.direction` → 0~359° 정수. 녹음과 동시에 폴링 가능.

## 개발 단계 참고
- **노트북 단계**: 내장 마이크 1채널이면 분류·접근·STT를 확인할 수 있고 방향은 미상이다.
- **Jetson 단계**: 6채널로 열어 ch0=분류·접근·STT, ch1~4=방향으로 사용한다.
- 마이크 어레이 **장착 방향**(어느 마이크가 "전방")이 각도 기준 → 장착 기준 정해둘 것.
