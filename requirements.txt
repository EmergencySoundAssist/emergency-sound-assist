# 설치 (Mac/일반):
#   python3 -m venv .venv && source .venv/bin/activate && pip install -U pip

#   pip install -e ".[multisource]"   # + 다중음원 SRP/MUSIC: scipy, sounddevice, pyroomacoustics
#   pip install -e ".[dev]"           # + 테스트: pytest
#
# ⚠️ Jetson(JetPack/aarch64)은 conda 불가 → 반드시 venv. 상세 절차/시스템 패키지: docs/doa/jetson.md
#
# 아래 한 줄은 '전체 개발 환경'(다중음원 + 테스트)을 한 번에 설치한다.
-e .[multisource,dev]
